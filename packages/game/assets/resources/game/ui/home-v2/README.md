# 现代化导航栏 - 雪碧图优化

## 概述
使用雪碧图技术优化导航栏图标加载，将 4 个独立的图标合并为一张纹理，减少 DrawCall 和内存占用。

## 文件说明

### 生成的资源
- `nav_sprite_sheet.png` - 雪碧图纹理 (576x144)，包含 4 个图标水平排列
- `nav_sprite_sheet.json` - 雪碧图配置文件，定义每个图标的位置和尺寸

### 独立图标（用于生成雪碧图）
- `icon_collection.png` - 图鉴图标 (144x144)
- `icon_shop.png` - 商店图标 (144x144)
- `icon_tasks.png` - 任务图标 (144x144)
- `icon_settings.png` - 设置图标 (144x144)

## 技术特点

### 性能优化
- **减少 DrawCall**：4 个图标共用一张纹理，从 4 次绘制减少到 1 次
- **降低内存**：共享纹理缓存，避免重复加载
- **批处理友好**：相同纹理的元素更容易被引擎批处理

### 雪碧图配置
```json
{
  "width": 576,
  "height": 144,
  "icons": [
    { "name": "collection", "x": 0, "y": 0, "width": 144, "height": 144 },
    { "name": "shop", "x": 144, "y": 0, "width": 144, "height": 144 },
    { "name": "tasks", "x": 288, "y": 0, "width": 144, "height": 144 },
    { "name": "settings", "x": 432, "y": 0, "width": 144, "height": 144 }
  ]
}
```

### 使用方式
`ModernNavDock` 组件会自动：
1. 加载雪碧图纹理和配置文件
2. 根据图标名称从配置中查找位置
3. 使用 `SpriteFrame.rect` 裁剪出对应区域
4. 应用到导航按钮

## 设计风格
- **温暖木质色调**：主色 #FCE5CB，边框 #A97B50
- **可爱圆润**：84px 圆形按钮，带外发光效果
- **细腻质感**：高光、分隔线、内阴影多层叠加
- **微动效**：悬浮动画、点击反馈、任务徽章脉冲

## 图标生成
所有图标由 Stitch 设计工具生成，风格统一：
- 尺寸：144x144 px
- 风格：可爱、温暖、圆润
- 色调：橙色系，与游戏主题契合
- 特点：简洁清晰，易于识别
