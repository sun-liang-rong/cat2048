# 猫咪合成2048 首页重设计说明

## 修改内容

根据设计稿对游戏首页进行了一比一还原，主要修改包括：

### 1. 顶部标题栏
- **标题样式优化**：
  - 添加装饰性猫耳朵表情符号 🐺
  - "猫咪合成"使用深褐色 (#8B5A3C)
  - "2048"使用橙黄色 (#FFB84D)
  - 调整字号：主标题 28px，数字 32px
  
- **金币显示优化**：
  - 添加"金币"文字标签
  - 调整布局：金币图标 + "金币" + 数量 + 加号按钮
  - 优化间距和圆角，使用更柔和的白色背景
  - 金币图标 28px，数字 20px

### 2. 游戏场景区域
- 调整边距，向上移动场景位置（margin-top: -30px）
- 向下扩展场景（margin-bottom: -40px），让场景更贴近底部按钮
- 最大宽度调整为 480px
- 增强阴影效果，drop-shadow 更柔和

### 3. 底部操作按钮
- **布局调整**：
  - 使用 `align-items: flex-end` 让按钮底部对齐
  - 减小间距到 16px
  - 中间的猫爪按钮增加 margin: 0 8px 保持突出感
  
- **猫爪按钮**：
  - 尺寸增大到 180px × 180px
  - 添加脉冲动画效果（paw-pulse）
  - 增强阴影和光晕效果
  - "继续游戏"文字位置微调
  
- **侧边按钮**：
  - 缩小到 72px × 72px
  - 添加底部内边距让标签与猫爪按钮底部对齐
  - 添加阴影效果

### 4. 底部导航栏
- **背景优化**：
  - 使用渐变背景：从奶白色到米黄色
  - 添加顶部白色边框增强层次感
  
- **图标和标签**：
  - 图标尺寸调整为 52px × 52px
  - 雪碧图尺寸更新为 624px × 156px
  - 标签字号 13px，添加白色文字阴影
  - 优化间距和布局

### 5. 响应式优化
- 完善小屏幕适配（max-width: 480px）
- 优化横屏模式布局
- 保持安全区域适配（safe-area-inset-bottom）

## 设计特点

1. **温馨可爱风格**：使用暖色调和柔和的阴影
2. **视觉层次分明**：通过尺寸、阴影和间距强调主要操作按钮
3. **细节打磨**：添加动画效果和光晕，提升交互感
4. **适配完善**：支持不同屏幕尺寸和方向

## 技术要点

- 使用雪碧图优化底部导航图标加载
- CSS动画实现猫爪按钮呼吸效果
- Flexbox布局实现灵活的响应式设计
- Drop-shadow 和 box-shadow 结合使用增强视觉效果
