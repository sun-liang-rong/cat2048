# Cat2048Boot Split Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Split the 1070-line `Cat2048Boot.ts` monolith into focused presentation modules so future features (ads, collection, challenge mode) can land without growing a single god-component, while preserving all current gameplay, UI, and tests.

**Architecture:** Keep `@ccclass('Cat2048Boot')` as the only Cocos scene Component and app shell (lifecycle, canvas, navigation, shared services). Extract plain TypeScript view/controller classes that Boot constructs and owns—no new scene `.meta` wiring. Pure board geometry and async tween helpers become unit-tested first; Cocos-bound views move second via mechanical extraction with typecheck + existing Vitest as the safety net. Behavior must not change.

**Tech Stack:** TypeScript, Cocos Creator 3.8.8, Vitest 2

**Prerequisite:** Finish or stash the in-progress haptics-setting work first so this refactor has a clean baseline. Prefer committing haptics (`docs/superpowers/plans/2026-07-30-haptics-setting.md`) before Task 1.

**Non-goals:**
- No new product features (ads, revive, collection, mid-game save).
- No Cocos multi-scene navigation or editor scene rewiring.
- No visual redesign; pixel/layout parity with current Boot.
- No moving core rules out of `core/` or storage out of `infrastructure/`.

export const BOARD_PIXELS = 690;
export const BOARD_PADDING = 18;
export const CELL_GAP = 10;
export const CELL_SIZE = (BOARD_PIXELS - BOARD_PADDING * 2 - CELL_GAP * 3) / 4;

/** Board-local center for a grid cell. Origin is board center; +Y is up. */
export function cellCenter({ row, col }: Position): { x: number; y: number } {

}

export function tweenPosition(node: Node, position: Vec3, seconds: number): Promise<void> {
  return new Promise((resolve) => {
    tween(node).to(seconds, { position }, { easing: 'quadOut' }).call(() => resolve()).start();
  });
}

export function tweenScale(node: Node, scale: Vec3, seconds: number): Promise<void> {
  return new Promise((resolve) => {
    tween(node).to(seconds, { scale }, { easing: 'backOut' }).call(() => resolve()).start();
  });
}

export function tweenOpacity(node: Node, opacity: number, seconds: number): Promise<void> {
  const target = node.getComponent(UIOpacity) ?? node.addComponent(UIOpacity);
  return new Promise((resolve) => {
    tween(target).to(seconds, { opacity }).call(() => resolve()).start();

}

- [ ] **Step 1: Implement swipe helper**

```ts
import { EventTouch, Node, Vec2 } from 'cc';
import type { Direction } from '../core/types';
import { GAME_CONFIG } from '../infrastructure/gameConfig';

export type SwipeHandler = (direction: Direction) => void;

export class SwipeInput {
  private touchStart: Vec2 | null = null;

  public constructor(
    private readonly isLocked: () => boolean,
    private readonly onSwipe: SwipeHandler,
    private readonly onTouchStartLocal?: (localX: number, localY: number) => void,
    private readonly onTouchEndOrCancel?: () => void,
  ) {}

  public bind(board: Node, toLocal: (uiX: number, uiY: number) => { x: number; y: number } | null): void {
    board.on(Node.EventType.TOUCH_START, (event: EventTouch) => {
      if (this.isLocked()) return;
      this.touchStart = event.getUILocation();
      const ui = event.getUILocation();
      const local = toLocal(ui.x, ui.y);
      if (local) this.onTouchStartLocal?.(local.x, local.y);
    });
    board.on(Node.EventType.TOUCH_CANCEL, () => {
      this.touchStart = null;
      this.onTouchEndOrCancel?.();
    });
    board.on(Node.EventType.TOUCH_END, (event: EventTouch) => {
      this.onTouchEndOrCancel?.();
      if (!this.touchStart || this.isLocked()) return;
      const end = event.getUILocation();
      const dx = end.x - this.touchStart.x;
      const dy = end.y - this.touchStart.y;
      this.touchStart = null;
      if (Math.max(Math.abs(dx), Math.abs(dy)) < GAME_CONFIG.swipeThreshold) return;
      const direction: Direction = Math.abs(dx) > Math.abs(dy)
        ? (dx > 0 ? 'right' : 'left')
        : (dy > 0 ? 'up' : 'down');
      this.onSwipe(direction);
    });
  }

  public reset(): void {
    this.touchStart = null;
  }
}
```

export function directionFromDelta(dx: number, dy: number, threshold: number): Direction | null {
  if (Math.max(Math.abs(dx), Math.abs(dy)) < threshold) return null;
  return Math.abs(dx) > Math.abs(dy)
    ? (dx > 0 ? 'right' : 'left')

## Risk controls

1. **One extraction per commit** — easy bisect if animation or layout breaks.
2. **No behavior edits in the same commit as a move** — if a bug is found, fix in a follow-up commit.
3. **`sceneToken` / `isAlive`** — every async animation path must abort after `clearScreen`.
4. **Input lock** — `SwipeInput`, item buttons, and dialogs must share Boot’s `inputLocked`.
5. **Do not rebind the scene component name** — `@ccclass('Cat2048Boot')` and `main.scene` stay as-is.
