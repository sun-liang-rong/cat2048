# 猫咪2048微信小游戏开发需求规格说明书（V1.0）

## 1. 文档概述
本文档为微信小游戏“猫咪2048”的完整产品与技术需求。项目基于成熟的开源2048底层逻辑（滑动、合并、随机刷新），使用Cocos Creator打包微信小游戏。核心工作为替换美术、文案、数值，并围绕IAA变现搭建模式、道具、图鉴、任务、广告系统。所有功能设计均以最大化激励广告收入与用户留存为目标。

## 2. 术语定义
- **猫咪方块**：棋盘上每个可移动的单位，具有等级与品种。
- **猫爪金币**：游戏内软货币，仅用于购买纯装饰性内容，不影响核心玩法。
- **道具**：消耗性功能物品，仅通过广告或分享获得，不可金币购买。
- **图鉴**：永久收集系统，记录各等级猫咪解锁状态。
- **Lv X**：猫咪等级，数字越大越高级。

## 3. 核心玩法与规则

### 3.1 棋盘与操作
- 采用4×4标准网格，不可更改尺寸。
- 手指在屏幕上、下、左、右滑动，所有方块向该方向整体移动，直至触碰边界或不同等级方块。
- 同等级且同品种的猫咪方块发生碰撞时，合并为高一级猫咪（品种按固定链路进化，见3.2）。合并后的方块置于移动方向最前端。
- 每次有效滑动（至少发生一次移动或合并）后，系统在随机空白格子生成1只新猫咪。生成逻辑见数值配置。
- 当棋盘所有格子被占满且任何方向都无法产生移动时，本局结束，判定失败。

### 3.2 猫咪进化链路（不可变动）
| 等级 | 品种名称      | 立绘资源ID |
|------|---------------|------------|
| Lv1  | 橘猫          | cat_01     |
| Lv2  | 蓝白英短      | cat_02     |
| Lv3  | 三花猫        | cat_03     |
| Lv4  | 布偶猫        | cat_04     |
| Lv5  | 暹罗猫        | cat_05     |
| Lv6  | 美短虎斑      | cat_06     |
| Lv7  | 奶牛猫        | cat_07     |
| Lv8  | 纯黑孟买猫    | cat_08     |
| Lv9  | 银河极光猫    | cat_09     |
| Lv10 | 星穹守护猫    | cat_10     |
| Lv11 | 星环圣灵猫    | cat_11     |
| Lv12 | 创世极光猫    | cat_12     |

- Lv12为终极猫咪，不可再合并。一旦本局合成，立即永久点亮图鉴，且该局内无法继续向上合成。

### 3.3 计分规则
- 每次合并成功，获得本次合成后新猫咪等级对应的分数。
- 单次合并得分 = 2^等级。例如：合成Lv2得4分，Lv3得8分，……，Lv12得4096分。
- 当前局总分实时累加，结束时作为最终成绩。

### 3.4 失败与复活（两种模式通用）
- 棋盘无法移动时弹出“猫咪挤满啦”失败面板，展示本局得分、最高分。
- 面板提供“看广告复活”按钮。用户观看完整激励视频后，系统从棋盘上移除等级最低的2个猫咪方块（优先移除Lv1，若多个Lv1则随机），腾出空位，游戏继续。
- 每局限复活1次。

## 4. 游戏模式

### 4.1 经典无尽模式
- 无终点，以获取最高分数为目标。
- 分数实时上传，接入微信小游戏好友排行榜，主界面提供排行榜入口。
- 游戏结束可分享战绩卡片（带猫咪与分数）至微信群/好友。

### 4.2 图鉴闯关模式
- 该模式按猫咪品种设定固定关卡，玩家需要在有限条件下合成指定等级的猫咪通关。
- 关卡共8关，逐一解锁。每关目标、初始棋盘配置、过关奖励如下表。具体预设位置由配置表随机生成，但保证猫咪种类与数量。

| 关卡 | 目标合成猫咪   | 初始棋盘预设（均含若干空白格）            | 通关金币奖励 | 解锁图鉴       |
|------|----------------|-------------------------------------------|--------------|----------------|
| 1-1  | Lv2 蓝白英短   | 3个Lv1橘猫                                | 100          | 蓝白英短       |
| 1-2  | Lv3 三花猫     | 4个Lv1橘猫，1个Lv2蓝白英短                | 150          | 三花猫         |
| 1-3  | Lv4 布偶猫     | 3个Lv1，2个Lv2，1个Lv3三花猫              | 200          | 布偶猫         |
| 1-4  | Lv5 暹罗猫     | 2个Lv2，2个Lv3，1个Lv4布偶猫              | 250          | 暹罗猫         |
| 1-5  | Lv6 美短虎斑   | 2个Lv3，2个Lv4，1个Lv5暹罗猫              | 300          | 美短虎斑       |
| 1-6  | Lv7 奶牛猫     | 2个Lv4，2个Lv5，1个Lv6美短                | 350          | 奶牛猫         |
| 1-7  | Lv8 纯黑孟买猫 | 2个Lv5，2个Lv6，1个Lv7奶牛猫              | 400          | 纯黑孟买猫     |
| 1-8  | Lv9 银河极光猫 | 2个Lv6，2个Lv7，1个Lv8孟买猫              | 500          | 银河极光猫     |

- 关卡无步数限制。失败条件同经典模式（棋盘满且无法移动），失败后可看广告复活（规则同3.4）。复活不消耗任何道具。
- 通关后，对应猫咪图鉴自动点亮（若首次合成），并立即获得金币奖励。已通关卡不可重复挑战。

## 5. 道具系统
所有道具均不可用金币购买，必须通过观看激励视频广告或分享获取。每种道具持有上限为10个，达到上限后无法继续获取。

### 5.1 道具列表
| 道具名称   | 功能描述                                               | 获取方式与限制                                                                 |
|------------|--------------------------------------------------------|--------------------------------------------------------------------------------|
| 撤回步数   | 撤销上一步操作，棋盘状态回到滑动之前（仅撤回移动，不恢复已合成猫） | 每日登录赠送2个（不累积上限）；看1次激励视频得1个（每日限5次）；分享游戏给好友得2个（每日限1次） |
| 额外刷新   | 手动选择并生成1只Lv1橘猫或Lv2英短，填补随机空格          | 看1次激励视频兑换1个                                                            |
| 洗牌重排   | 棋盘上所有猫咪方块位置完全随机打乱（等级与品种不变）       | 看1次激励视频兑换1个                                                            |
| 消除单格   | 长按选择棋盘任意一个猫咪方块，直接将其清除留出空位         | 看1次激励视频兑换1个（作为高价值道具，视频时长可能为30s，以实际广告填充为准）         |

- 道具使用入口：游戏内常驻道具栏，即时生效。撤回和消除操作不可逆。

## 6. 经济系统与猫爪金币

### 6.1 猫爪金币产出
- 图鉴闯关关卡首通奖励。
- 图鉴收集奖励（每解锁3种猫咪）。
- 每日/每周任务奖励。
- 成就奖励。
- 不支持用现金购买，不提供金币内购。

### 6.2 金币用途
金币唯一作用是在“猫咪小屋”装饰商店内购买纯装饰内容，包括：
- 猫咪头像框（动态、静态）
- 棋盘格子底纹（猫爪印、小鱼干等）
- 游戏内聊天表情包（仅在分享图合成时使用）

装饰品均提供金币定价，同时商店每个装饰均并列提供“看广告免费解锁”选项。确保免费玩家可通过时间积累获得，付费意愿由广告替代。

> 注意：棋盘背景（原木猫窝、粉色少女卧室、星空）属于高阶皮肤，不放入商店，必须通过特定条件解锁并看广告激活（详见7.3）。

## 7. 猫咪图鉴与收集系统

### 7.1 图鉴页面
- 罗列Lv1~Lv12全部12种猫咪。未解锁猫咪以灰色剪影显示，锁定标志；已解锁显示彩色立绘、品种名、趣味简介（文案如“爱晒太阳的橘座”）。
- 点击已解锁猫咪可查看大图与毛色科普小知识。

### 7.2 解锁规则与奖励
- 在本局游戏中首次合成出某等级猫咪，即永久解锁该图鉴，无论模式。
- 每累计解锁3种猫咪，可领取猫爪金币奖励（第3只200，第6只400，第9只600，第12只800）。
- 集齐全部12种猫咪，获得“星空猫爪棋盘”皮肤的使用资格。在皮肤界面点击使用，需观看一次激励视频后永久解锁该棋盘背景。

### 7.3 棋盘背景皮肤
游戏提供3套可切换棋盘背景，获得方式如下：
| 背景名称       | 获取条件                           | 是否需广告激活 |
|----------------|------------------------------------|----------------|
| 原木猫窝       | 默认解锁                           | 否             |
| 粉色少女卧室   | 累计完成10个每日任务               | 是（看广告）   |
| 星空猫爪       | 集齐12种猫咪图鉴                   | 是（看广告）   |

### 7.4 成就系统
定义一系列一次性成就，触发时立即发放奖励，无需手动领取。部分成就示例：
- 初次相见：首次合成任意猫咪 → 金币100
- 小猫集合：单局内合成3只Lv3以上猫咪 → 撤回道具1个
- 高阶猫控：单局一次性合成5只Lv6及以上猫咪 → 洗牌道具1个
- 极光之主：累计合成10只银河极光猫 → 消除单格道具1个，专属头像框“极光”
- 百万猫爪：历史累计分数达到100000 → 金币500

## 8. 日常与每周任务

### 8.1 每日任务（每日0点刷新）
| 任务内容                             | 奖励               |
|--------------------------------------|--------------------|
| 游玩3局经典无尽模式（至少有效滑动1次） | 撤回道具×1        |
| 累计滑动50次                         | 猫爪金币200        |
| 合成布偶(Lv4)及以上猫咪2次           | 额外刷新道具×1    |
| 观看任意2次激励广告                  | 洗牌道具×1        |
- 全部4项完成后，可领取“每日宝箱”：猫爪金币300 + 随机道具1个。宝箱奖励领取时，可选择观看广告使金币翻倍（600）。

### 8.2 每周任务
- 一周内累计完成15次每日任务，即可领取当周限定猫咪头像框（动态，每周轮换，永久拥有）。
- 周任务进度在周日24点重置，未领取无法补领。

## 9. 微信广告点位规划（IAA核心）
严格遵循微信流量主规范，确保合规性与体验平衡。

### 9.1 激励视频广告点位（核心变现）
- **道具获取**：所有道具均通过激励视频兑换。
- **复活**：任何模式失败后看广告复活。
- **奖励翻倍**：每日宝箱、图鉴金币奖励、任务金币奖励均提供“看广告翻倍”按钮。
- **皮肤激活**：粉色少女卧室、星空猫爪背景，以及商店内部分高价装饰，需要观看广告激活。
- 所有激励视频需在回调成功后才发放奖励，严禁欺骗行为。

### 9.2 插屏广告点位
- 经典无尽模式对局结束后，展示全屏插屏广告，5秒后可关闭。单用户展示间隔不低于120秒。
- 图鉴闯关模式中，连续通关3个关卡后，在奖励弹窗关闭时展示插屏。
- 从图鉴页、任务页返回主界面时，概率展示插屏（概率30%，间隔条件同上）。

### 9.3 分享裂变
- 分享场景包括：分享最高分、分享集齐图鉴成就、每日首次分享获道具。
- 分享图片自动合成，包含玩家微信头像、昵称、当前得分/猫咪图案，底部带小程序码。
- 成功分享到微信群或好友后，调用`wx.shareAppMessage`的success回调，直接发放对应奖励（撤回道具×2）。每日仅限首次分享可得。

## 10. 美术与UI资源清单
包体需控制在40MB以内，所有资源采用压缩格式，立绘使用256×256像素PNG，背景图控制在300KB以下。

### 10.1 猫咪立绘（必备，12张）
正方形，扁平化软萌Q版，256×256px。文件名对应：cat_01~cat_12。低饱和度，浅色勾线，符合女性向审美。

### 10.2 棋盘与格子
- 通用空白格子底图：浅米色猫爪底纹，180×180px。
- 合并闪光特效：猫咪升级时出现的白色星光动画，3帧序列帧，播放时长0.2秒。

### 10.3 棋盘背景（3张）
- 原木猫窝：木质纹理底色，角落有毛线球。
- 粉色少女卧室：粉色系，散落猫玩具。
- 星空猫爪：深紫色星空，猫爪星座图案。

### 10.4 UI界面元素
- 主界面：模式选择按钮（经典无尽、图鉴闯关）、图鉴、任务、排行榜、装饰商店入口。
- 弹窗样式：圆角卡通边框，猫咪耳朵装饰，关闭按钮。
- 道具栏图标：撤回（弯曲箭头）、刷新（星星）、洗牌（骰子）、消除（橡皮擦），均64×64px。
- 猫爪金币图标：一只金色猫爪剪影。
- 头像框素材：至少6套（每周轮换+成就专属）。

## 11. 技术适配与微信接口对接

### 11.1 Cocos Creator配置
- 游戏设计分辨率：750×1334（竖屏），支持自动适配全屏，允许切换到横屏（界面自适应）。
- 将开源2048核心逻辑脚本挂载为节点组件，修改其中的猫咪品种、合并链路、刷新规则为本文档配置。不需要改动核心滑动算法。

### 11.2 微信开放能力接入
- `wx.setUserCloudStorage`：上传分数至微信排行榜，自动同步好友数据。
- `wx.getUserInfo`：获取昵称、头像用于排行榜展示。
- `wx.shareAppMessage`：自定义分享卡片，设置图片为动态合成的canvas快照。
- `wx.createRewardedVideoAd`：创建全局激励视频广告实例，统一管理广告ID。
- `wx.createInterstitialAd`：插屏广告实例，遵守展示间隔。
- 防沉迷：接入`wx.checkIsUserAdvisedToRest`，限制未成年登录时长、广告观看次数。
- 云存储：使用微信KV存储（`wx.setStorageSync`等）保存最高分、图鉴、道具数量、任务进度等，支持换手机后通过微信账号恢复。对于需要跨设备的场景，可接入`wx.setUserCloudStorage`存储关键数据。

## 13. 附录：开源代码对接关键点
1. **Grid & Tile管理**：保留原2048的`Tile`节点，将数字显示替换为根据等级显示对应猫咪立绘，并增加品种枚举值。
2. **合并逻辑**：在原始`move`和`merge`函数中插入判定：当前等级Lv合并后变成Lv+1猫咪品种，同时播放合并特效，累加分数。
3. **随机生成**：修改`addRandomTile`，按概率从Lv1、Lv2中选取，并实例化对应猫方块。
4. **游戏结束检测**：保留原有`isGameOver`方法，增加失败面板弹出和复活逻辑入口。
5. 扩展模式、道具、任务等均基于该核心外部新增管理器，不侵入核心算法。
